# ScriptRunnerBar

> Run any script, anytime, with just a click.

A native macOS menu bar app that lists scripts from a folder and runs them with arguments and live streaming output.

## Install

Requires macOS 15 or later.

```bash
brew install G1J0SHI/tap/scriptrunnerbar
scriptrunnerbar
```

To uninstall: `brew uninstall scriptrunnerbar`

## Shortcuts

| Shortcut       | Action                              |
| -------------- | ----------------------------------- |
| `⌘F`           | Filter scripts                      |
| `⌘N`           | New script from template            |
| `⌘R`           | Refresh folder                      |
| `⌘.`           | Stop all running scripts            |
| `⌘,`           | Settings (folder & Launch at Login) |
| `⇧⌘C` / `⌘K`   | Copy / clear output                 |
| `⇧⌘]` / `⇧⌘[`  | Next / previous tab                 |
| `⇧⌘W` / `⌥⇧⌘W` | Close tab / close all finished tabs |
| `Esc`          | Clear filter / hide window          |
